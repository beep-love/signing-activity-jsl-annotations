# Inference weights

This directory includes pretrained weights (`<variant>.pt`) and corresponding
JSON settings (`<variant>.json`) for Hands (`hands`), Eyes (`eyes`), Mouth (`mouth`),
and Hands + Eyes + Mouth (`hands_eyes_mouth`).

The supplied weights are from models trained on the Public DGS Corpus.
When using these weights, cite the corresponding
[DGS-Korpus publications](https://www.sign-lang.uni-hamburg.de/dgs-korpus/publications.html).

See the [example README](../README.md) for usage and
[LICENSE_WEIGHTS.md](LICENSE_WEIGHTS.md) for the weight usage terms.
